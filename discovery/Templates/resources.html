🧠Drug Prediction Model

The drug_model.pkl file contains a trained XGBoost model that predicts potential drug treatments based on disease input. It captures complex relationships between diseases and drug therapies.

The embedding_model.pkl stores a SentenceTransformer model used to convert disease descriptions into dense vectors for semantic similarity.

The mlb.pkl contains a MultiLabelBinarizer object that handles multi-label drug outputs and converts predictions between text and binary format.
