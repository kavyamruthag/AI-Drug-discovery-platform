🧠Drug Prediction Model

The drug_model.pkl file contains a pre-trained XGBoost machine learning model that predicts potential drug treatments based on input disease or protein deficiencies. This model has been trained using the drug dataset and has learned complex relationships between diseases and available drug treatments. By leveraging this model, researchers or developers can quickly identify candidate drugs for a given disease, saving time and improving efficiency in drug discovery workflows. Purpose: Prediction | Type: PKL | Trained on: Drug dataset | Used for automated drug recommendation

🧠Embedding Model

The embedding_model.pkl file contains a pre-trained SentenceTransformer model that converts textual disease descriptions into dense numerical vectors. These embeddings allow the system to measure semantic similarity between user input and known disease descriptions, improving the accuracy of predictions. It is a crucial component for handling natural language inputs and making the model context-aware for unseen or complex disease descriptions. Purpose: Feature extraction | Type: PKL | Model: SBERT | Helps compare textual similarity between diseases

🧠mlb model

The mlb.pkl file usually contains a MultiLabelBinarizer object from scikit-learn. Its purpose is handling multi-label outputs in machine learning, which is exactly what your drug prediction project needs.Purpose: Convert drug names to binary format for training and back to names for prediction. Problem it solves: Multi-label classification for diseases → multiple drugs. File mlb.pkl: Contains the fitted binarizer to decode predictions after training.Machine learning models cannot work with strings directly. They need numbers. MultiLabelBinarizer converts these lists into vectors

💻Training Script

The train_model.py script contains the complete Python code for training the drug prediction model. It loads the dataset, preprocesses the data, trains the XGBoost model, evaluates its performance, and saves the trained model to a PKL file. This script can be modified for retraining with new datasets or improving model performance, making it a flexible and reusable tool for experimentation and research. Purpose: Model training | Type: PY | Dependencies: XGBoost, Pandas, NumPy | Supports retraining and evaluation
