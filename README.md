# AI Drug Discovery Platform

## 🚀 Overview

This project predicts drug properties, dosage, and disease relationships using machine learning models.

## 🛠️ Tech Stack

* Python
* Django
* Machine Learning (Scikit-learn)
* HTML, CSS

## ⚙️ Features

* Drug prediction system
* Disease deficiency analysis
* Dosage recommendation
* Admin dashboard

## 📂 Note

Due to size limitations, trained model files (.pkl) are not included.
Run training scripts to regenerate models.

## ▶️ How to Run

1. Clone the repository
2. Install requirements: `pip install -r requirements.txt`
3. Run server: `python manage.py runserver
